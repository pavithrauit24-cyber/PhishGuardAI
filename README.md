# PhishGuard — Phishing Awareness Prototype

PhishGuard is a small browser-based educational prototype that highlights common phishing warning signs in pasted email or text-message content.

## Features
- Runs as a static web page; no backend or API key required.
- Checks for urgency, requests for sensitive information, common lure wording, and a few suspicious URL characteristics.
- Explains the warning signs detected.
- Includes a safety checklist.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Click **Load sample**, then **Analyze message**.

No installation is required.

## Important limitations
This version uses transparent, rule-based heuristics. It is **not a trained AI model**, does not verify sender identity, does not open links, and cannot prove that a message is safe or malicious. A low-risk result does not mean a message is safe. Do not paste real private messages or sensitive personal data into public demos.
